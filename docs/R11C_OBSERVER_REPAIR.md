# R11c：RSZ2／WDMA2 帧尾与并行表面检查包

R11b 实机取得122条合格HEVC等待向量，原始系统调用号仍为0，PC／原厂指令、对象、栈及缓冲关联通过。另一方面，4次右端指纹变化落在跨请求切换向量，原正式统计正确排除；10次取结果路径计数前进后，到下一原生请求头发布仍有保守下界2–10ms。主延迟仍在bit6→bit2（约42.207ms），普通周期约41.738ms，未精确分解到RSZ2、WDMA2、HEVC或DDR。完整实机报告见 R11B_CAMERA_REPORT.txt。

R11b有13个窗口触及CPU软预算，追加完整联合校验会挤压尾部覆盖。R11c保持原有严格锚点，在锚点之间加入较轻的帧尾读，而不放宽身份或同请求判据。

## 生产变化

- **共享完整身份快照。** 每一侧的相机／source／HAL类型和根对象快照，同时供原stage身份及HEVC联合证明使用，避免重复解引用。PC和运行中字节、HEVC semaphore、线程前后视图／starttime、原厂返回栈、fd路径及Que代际要求保留。ARM端点用例中，同一完整锚点的process读取从28次降至20次，身份字段相同；这不是实机CPU耗时保证。
- **混合窗口。** 录像窗口最多32个观察点，通常每4个点保存1个原完整锚点，其间为新的帧尾记录。原completion pending命中时优先执行既有最多2次同请求完整补读，不被轻量读替代。预览仍最多16个完整点。100ms快读、完整冷映射、12ms CPU／80ms墙钟软预算及停止后四文件导出保持。
- **六个底行探针。** 轻量记录只读Y底行2159与UV底行1079，各取byte16、1920、3824起始的16字节，覆盖左／中／右。原完整锚点的六探针保留；合计8个不同空间位置。只允许已验证的type7／3840 stride／2160 Y／1080 UV及CAP物理范围，不任意扫描内存。
- **RSZ2／WDMA2上下文。** 成对保留原厂RSZ2→WDMA2 mux、WDMA2布局、输入RDMA0、原生CORE和DMA分发状态／软件mask、原生RSZ计数。D0／D4／D8三个既有只读状态寄存器合并为恰好12字节读取；不包含ACK空洞。原厂debug E0只有B0原已为2才读，前后仍为2才标为可用，不改选择器，也不给未核实位赋忙时间意义。
- **并行表面上下文。** 每个轻量记录成对保存当前HEVC提交描述符和取结果路径计数。只有物理范围及相机映射通过，才列出与当前WDMA输出不同的表面候选。分析还可关联同一job的前后合格HEVC锚点；这不证明中间始终等待，也不证明两个硬件始终忙或量得DDR流量。
- **跨请求单列。** 新记录保存两个完整原生头和每项读取掩码。只有两端分别匹配原生环、类型／模式稳定、映射有效、请求恰相邻，才标记过渡候选；从不升级为原正式同请求数据。相同地址复用、跳号、模式更换和失败读取仍拒绝关联。没有缓存旧缓冲指针跨窗口补读，也不解引用已归还的Que元数据。

## 格式与判读

buffer-flow为schema5，仍为1024字节record、1000条上限；kind4沿用严格完整锚点，kind9为帧尾记录。窗口结束数按两类观察点合计核对。原schema1/2/3/4不追溯补全新探针或缺口。

kind9的d[]布局：

| 字段 | 原始内容 |
|---|---|
| 0..31 | 两个完整原生头 |
| 32..41 | WDMA2配置前／后各5字 |
| 42..57 | 相机／source／HAL身份前／后各8字 |
| 58..81 | HAL字段及32字节提交描述符前／后 |
| 82..94 | 六探针地址、指纹及成功掩码 |
| 95..97 | 只读寄存器掩码、对象掩码、策略1 |
| 98..129 | mux、DMA／CORE状态及mask、原生RSZ计数、RDMA0、模式、受守卫debug原值 |
| 130..136 | 库基址、预期相机／source／HAL、先前完整锚点序号及间隔4 |

无活动原生头时只读初始RAM头。相机／source／HAL在第二次身份检查中失败或更换后，禁止第二侧MMIO，只保留最终原生RAM头。没有旧缓冲的延迟重读；六个指纹只来自本记录首侧已验证输出表面。

正式帧尾变化需要同请求身份、布局、输入地址及完整前后映射通过；过渡变化单独报告。HEVC取结果计数仅表示原厂result ioctl返回路径前进，返回状态未保存，不能当成功输出或同缓冲物理释放。EOF路由未启用时仍为不可用。DDR带宽、stall周期和RSZ2／WDMA2独立busy时间均保持未知。

## 保持不变与验证边界

RTOS入口、event10、bit6、首末输入绑定、全宽helper和21项保护路径逐字节保持。采集器RAM数据文件仍18,560,000字节，观察上下文仍限定8192字节，像素映射缓存64页；无额外RTOS／CAP图像分配。无设备写入、ACK、IRQ使能、选择器修改、ptrace、fork、相机信号或目标函数调用。没有更改全宽几何、时钟、QOS、码率和处理流程。

验证包括真实生产ARM的帧尾／过渡／模式生命周期／部分读／debug守卫／白名单边界和读取成本用例，保持HEVC联合判定正负矩阵、完整混合采样和四文件保存，以及R10r至R11b历史实机回归。OS、DMA、缓存、调度和读取成本仍有模型，不能替代这版的相机短测，也不能据此宣布帧率修复。

只需一次35／120／35秒合并测试，见 R11C_TEST_STEPS.md。预期用左右／中部可见写入、原生请求转换和HEVC另一表面取结果的先后关系进一步收窄范围；没有可直接量化DDR争用的硬件计数器时，不自动归因。
