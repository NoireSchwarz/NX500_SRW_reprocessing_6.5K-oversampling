# NX500 RC6.14.10 無線連線

適用於 Samsung NX500 原廠韌體 1.12。短按 Wi-Fi，選定一項後按 OK 或點按該項。左碼加入相機熱點，右碼打開手機網頁。再按一次 Wi-Fi 會停止並退出。

| 相機選項 | 連線及用途 |
| --- | --- |
| 5 GHz 相簿 | 沿用主信道 48、副信道 44、中心 46、40 MHz 的中國大陸室內配置。瀏覽相簿、下載原檔及查看相機資訊 |
| 2.4 GHz 相簿 | 使用原廠熱點。相簿、原檔下載及相機資訊與 5 GHz 相簿相同 |
| 2.4 GHz 圖傳 | 使用原廠 Remote Viewfinder，手機瀏覽器連續接收 720×480 JPEG，支援全螢幕 |

選擇 2.4 GHz 相簿或圖傳後，確認原廠熱點的實際頻率才顯示雙碼。EV+Wi-Fi 照常切換 V-Log。

## 安裝

1. 先核對 ZIP 的 SHA-256，備份原有照片、影片、完整備份和歷史日誌。
2. 相機關機並等寫卡燈熄滅。將 ZIP 中的 `install.sh`、`info.tg`、`nx_cs.adj`、`nx-lut-demo/` 和 `looks/` 解壓到 SD 根目錄，合併同名安裝目錄。保留 `DCIM/`、`SYSTEM/` 和 `NXDEMO51/`。
3. 安全退出 USB，取出電池約 30 秒再裝回開機。按相機上的安裝提示操作，待安裝完成後關機再開機。首次啟動模組時，依相機提示開啟藍牙。已有快啟設定的相機繼續使用現有休眠鏡像。
4. 在 EV+AEL 選單的視頻頁確認 RC6.14.10。卡上的 `NXDEMO51/logs/install.log` 會記錄 `INSTALL_COMPLETE`。

## 合併短測

1. 選「5 GHz 相簿」，依序掃兩個碼，打開相機資訊並下載一個現有原檔。用 Wi-Fi 鍵關閉並等候回到取景。
2. 選「2.4 GHz 相簿」，確認同一份原檔可下載。再按 Wi-Fi 關閉。
3. 選「2.4 GHz 圖傳」，確認連續取景和全螢幕切換。先關閉手機網頁讓 RVF 退出，再開一次，用機身 Wi-Fi 鍵停止。
4. 回到照片取景後，按 EV+Wi-Fi 核對 V-Log 快捷鍵。寫卡燈熄滅後可接回 USB。

電腦端驗證涵蓋啟停、錯誤頻段拒絕、原廠 RVF 恢復、安裝升級和套件讀回。RC6.14.10 的實機驗收待完成。
