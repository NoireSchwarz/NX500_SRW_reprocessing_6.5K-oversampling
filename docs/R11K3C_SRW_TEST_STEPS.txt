A1 SOURCE 19 → B1 LINEAR TEST → B2 LOG TRANSFER TEST → A2 SOURCE 19。
每次等待JPEG保存完整、资源归还，再换下一项。跳过菜单循环中的FACTORY/LIFT，不用它们代替SOURCE19返回对照。临时LINEAR/LOG不会保存成重启默认，每次执行前核对选项。
