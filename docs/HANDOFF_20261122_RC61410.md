# NX500 RC6.14.10 Wi-Fi 交接

2026-11-22。基線為已安裝並短測的 RC6.14.9。2.4 GHz 平放全段相機平均推送 27.95 fps，跳幀 6.8%，TCP 重傳 0。5 GHz 第一段為 26.05 fps，跳幀 12.7%，重傳 80。貼機近場在起播後約 9.9 秒穩定推送約 30 fps。5 GHz 相簿的大檔相機端長傳平均 6.19 MB/s。這些數值來自 RC6.14.9。

## 入口和恢復

- menu_wifi.inc 將相機標題、啟動指令和雙碼網址綁在同一張表。5 GHz 相簿呼叫 hotspot，2.4 GHz 相簿呼叫 hotspot24，2.4 GHz 圖傳呼叫 rvf。
- wifi.sh 在進入 2.4 GHz 相簿前核實無未恢復的 5 GHz 租約。原廠 SoftAP 啟動後由 wifi-server.c 讀取實際頻率，通過才啟動網頁。已啟動的熱點在確認或網頁啟動失敗後會走停止流程。
- RVF 只接受原廠 2.4 GHz 頻率。已移除 5 GHz RVF 的選單和啟動命令，保留舊版未完成的無線恢復入口。相簿提供原檔下載和資訊頁。
- 原廠 RVF JPEG 長連線、全螢幕和 TCP 記錄沿用 RC6.14.9。記錄續寫到 NXDEMO51/logs/wifi-rvf-rc614.log 和 wifi-rvf-tcp-rc6148.log。2.4 GHz 的 width_mhz=0 表示該入口未讀取頻寬。

## 構建和驗證

work/r10k-ep-flow/base/nx-lut-lite/ 收錄本版選單、按鍵、Wi-Fi 服務、網頁與殼層來源。installer/rc61410/ 收錄對應安裝入口與清單。完整安裝資源在 Release ZIP。

在專案既有 Python、Zig 0.13 與 ARM soft-float musl 工具鏈下，透過 base/nx-lut-lite/tools/build_zig.py --menu-only 重建選單，透過 core/tools/build_front.py 分別編譯 wifi-server.c、wifi-radio.c。先構建 Wi-Fi 服務後更新 radio contract 的長度與 FNV，再重建 radio。修改執行檔後須重新綁定 Wi-Fi 資源清單、安裝清單與入口 SHA-256。原廠韌體及開發機工具鏈由開發者另行提供。
