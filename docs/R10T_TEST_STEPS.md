# R10t：已注册 owner 与失败快照短测

R10s 已确认安装、全宽应用和采样保存成功，稳定录像104/104帧各命中一次event10；对象快照9次尝试全被拒绝。R10t 保留相同event10入口、RTOS、全宽helper和拍摄配置，只增加Linux只读对象证据及版本标记。本版尚未证明提升帧率。

1. 安全弹出SD，装回相机完成安装，随后**完整关机再开机、断开USB**。视频页应显示 **R10t LDC OWNER DIAGNOSTIC**。
2. 照片模式应用 **FULL WIDTH 4K 30P**，按提示重新选择 **NTSC／UHD30p／PRO**，再回照片模式。保持此前码率和默认BUS QOS，不做码率或裁切对照。
3. 开启 **STAGE COUNTERS**，确认 **ON / STOP+SAVE**，退出补丁菜单进入视频取景。
4. **取景3秒 → 录像6秒 → 停录后取景3秒**。
5. 回照片模式停止保存，等 **COUNTERS SAVED - SAFE TO CONNECT USB** 后再连接USB。总采样尽量少于25秒；菜单操作较慢时正常停止保存即可，不要为赶时间中途断电。

保留新生成的 VIDEO_FULL_*、VIDEO_STAGE_*、对应MP4和安装日志。如报错，记下屏幕原文及发生步骤；不要清理日志、格式化或修复文件系统。

后续检查：

- 安装revision为 `recovery-r10t-ldc-owner-diagnostics`，采样revision为 `R10t LDC_OWNER_DIAG_COUNTERS`。
- producer仍为9，route升为4。最多保留3条通过校验的快照和最近1条被拒绝快照，另记全部拒绝次数；更早的拒绝快照会被覆盖，不会冒充完整失败历史。
- 每次快照保存前/后owner、策略字段、View/Still成员、类型、读取成功掩码，及首个诊断问题和阻止关联的具体阶段。读失败与读到零值分开表示。
- owner类型按原厂已注册通知接口和精确主/次类型独立核验；View/Still须与对应原厂成员一致。策略字段为空仍保留证据，不等于相机对象损坏。停止/关闭状态不能用于正式分段统计。
- 稳定录像每帧一次、无计数饱和/owner变化，计时/模式/来源一致，覆盖与预算标志如实保留。

全宽helper和RTOS保留R10r二进制，应用阶段日志仍可能写R10r；以安装清单、采样revision与route4共同确认新版。HEVC断点停用标记是预期状态。类型关联通过仍不证明同一DMA缓冲、连续生命周期或纯硬件忙时间；部署到SD不表示相机已安装运行。
