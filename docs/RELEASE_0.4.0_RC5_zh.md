## RC5 更新

- **普通 LUT 默认用于视频**：按 OK 应用非零普通 LUT 后，同步开启已验证的影片 LUT 路径；菜单仍可手动关闭。再次应用 LUT 会恢复默认开启。冷启动不自动应用 LUT；强度全零及原厂恢复仍回到原厂基准。
- **EV+WiFi 切换 V‑Log**：完全放开组合键后执行一次。根据既有 Gamma 命令锁内的实际状态选择开启或恢复；过渡或失败状态优先提供恢复。AEL+WiFi 没有新增绑定。
- **双击 EV 打开当前 LUT 详细页**：取代 RC4 的三按。按已经应用的收据恢复普通 LUT／Log LUT 及 A/B 参数，不把未提交草稿当作已生效设置。单按 EV 原有功能保留，最多延后约 420ms 判断。
- **菜单内也支持 V‑Log 快捷键**：与后台按键监听器避免重复提交；详细页切换成功后按新输入状态转到普通／Log 范围。
- EV+AEL 菜单、OK 确认后装载、菜单保持打开及半按返回取景均保留。

## 已合并的 RC1–RC4 功能

- 繁体中文菜单；普通 LUT 半屏详细页、浓淡／色相／锐度／对比参数；独立强度归一化的 M3 A/B 混合。
- 32 张正式 LUT：25 张普通输入、7 张 V‑Log 输入，带简介。Log LUT 仅能在 VID 专用入口选择，普通 A/B 和 SRW 均不能选。
- SRW 五项精简菜单；初始化并重显影会自动准备工作阶段；移除面向用户的测试开关。
- 二级窗口期间临时独占输入，避免拨轮同时改变原厂曝光参数。
- RC4 的完整一次性 LUT 重载：取景 EOF 同步、完整传输顺序、完成确认及退出 Access 状态。只移植 metol 单次装载，不引入其视频监看器。
- 视频规格重载复用原厂 resolution 命令；全宽 UHD24、UHD 转 2.5K、恢复原厂 UHD 不再要求用户手动重选原厂视频尺寸。

## 验证与边界

RC5 已通过真实 ARM 菜单／按键控制流、真实 shell 与 ARM LUT 工具、正式安装器升级回放、组件身份、ZIP CRC 和整包清单检查。OS、Gamma、MMIO、中断和相机端点仍有模拟。

RC4 获用户反馈“效果很好”。**RC5 新快捷键和默认值已部署到 SD，但尚未收到独立的 RC5 相机安装日志及短测回执**，因此保持 RC／预发布状态。不要把用户对 RC4 的认可写成 RC5 已完成实机验收。

本轮回放覆盖已安装 RC4 的升级；没有据此保证所有新机、旧包及挂起激活状态均已验收。核心库、RTOS、原厂 Gamma／色彩入口、原生 SRW、RC4 两个重载工具及全部 32 张 LUT 与 RC4 逐字节保持一致。

现行路线为 **8bit V‑Log／V‑Gamut 兼容实现**，不是 10bit 编码或厂商认证。物理 18% 灰、源原色／白点的独立标定及完整颜色残差尚有边界；MP4 原厂颜色标签未自动改写。取景和写卡仍共用所选变换，未实现独立原色视频监看与 Log 写卡分流。

全宽真实稳定 30p 的瓶颈归因仍未完成；可用路线优先原生 24p，不把 24p 交付称为 30p 提速修复。

## 安装和合并短测

1. 安全断开 USB，关机待写卡灯熄灭，取出电池约 30 秒，再装回安装；完成后关机再开机，确认 VID 页 `0.4.0 RC5`。
2. 照片待机应用普通 LUT，OK 后确认影片 LUT 默认开启；半按回取景，录制约 5 秒核验。
3. 双击 EV，确认返回当前已应用 LUT 和参数；修改只暂存，OK 才装载。
4. 停录并回照片待机，EV+WiFi 开启纯 V‑Log；双击 EV 进入 Log LUT，选一张并 OK。
5. 再次停录回照片待机，EV+WiFi 恢复原厂；双击 EV 应回到普通 LUT 的原厂项。
6. 菜单打开时试一次 EV+WiFi，确认只切换一次；EV+AEL 仍可呼出菜单。

SRW 继续沿用既有入口：先还原 V‑Log、手动关闭影片 LUT，再选择源片／普通 LUT，初始化并重显影。不重复码率测试，不格式化、清理、修复文件系统或删除照片、录像、完整备份和历史日志。

完整包含运行文件、资源、对应 SOURCE／EVIDENCE、各资源说明和许可；源码仓库的 AGPL 许可不改变第三方 LUT、字体、运行库和原厂资源的归属。下载后先核对附件 SHA256。
