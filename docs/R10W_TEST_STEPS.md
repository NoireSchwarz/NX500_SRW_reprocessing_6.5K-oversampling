# R10w 一次全宽流水线短测

本版同时观察多个原厂完成标记，目标是缩小 bit6（CS0 帧开始）到 bit2（CS0 帧完成）之间的慢区间。帧率是否改善尚未经过实机验证。

1. SD 装回相机，等待安装完成，再完整关机、取出电池约10秒后开机；断开 USB。
2. 补丁视频页确认显示 **R10w PIPELINE MARKERS**。照片模式应用 **FULL WIDTH 4K 30P**，按提示在原厂菜单重新选择 **NTSC／UHD30p／PRO**，回照片模式。保持原来的码率设置和 BUS QOS，不做码率对比。
3. 按 **STAGE COUNTERS**，确认显示 **ON / STOP+SAVE**。停留约2秒，确认菜单和按键正常。这次不单独停止保存。
4. 退出补丁菜单，进入视频取景：**取景5秒 → 录像约60秒 → 停录后取景5秒**。保持机位、焦距、曝光、白平衡和对焦稳定。
5. 回照片模式，按 **STAGE COUNTERS** 停止保存，等待 **COUNTERS SAVED - SAFE TO CONNECT USB** 后再连接 USB。
6. 保留本次全部新 **VIDEO_FULL_***、**VIDEO_STAGE_*** 目录及对应 MP4。只需这一段全宽录像，不需原生裁切或多档码率测试。

若应用报错、开始采样失败、按键失去响应或保存失败，就结束本次流程，记下发生在哪一步和屏幕原文；恢复后保留卡上日志，无需重复整套测试。不要在录像或保存尚未完成时连接 USB。

回收数据后将核验相机内部安装清单、采集器 R10w、RTOS producer11 和快读格式3。RTOS 保持已通过 R10v 实测的代码，producer11 是本版预期值。

每个阶段会分别标记：本请求内观察到完成跳变、初读已置位、未启用、读取失败、跨请求或未观察到。中断可能很快清除短脉冲，未观察到不等于该阶段卡住。
