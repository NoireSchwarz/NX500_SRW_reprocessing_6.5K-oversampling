# R10p：修正全宽应用卡死缺陷

R10o 已撤回，请不要再应用或测试 R10o。R10p 恢复被覆盖的原厂 LCD 计时入口，观测代码只使用原来两个固定代码区；原厂控制字保持为零。保留硬件提交、EP WDMA2 回调、最终 IRQ、完成回调四个时间点。SRAM-load／CS0-start 两项计时暂时不采集，分析中显示不可用。

本版已通过真实 ARM 指令回放，尚未在你的相机上证明不再卡死，也未证明帧率提升。照片、录像、历史日志和原始固件全部保留，不重复码率对照。

1. 安全弹出 SD，装入相机完成安装。**完整关机再开机，断开 USB**；确认补丁菜单显示 **R10p SAFE EP OBSERVER**。必须重启清除 R10o 留在相机 RAM 中的旧代码。
2. 这轮先只验证“应用设置”：在照片模式按一次 **FULL WIDTH 4K 30P**，等待结果。能返回菜单且按键正常后，按提示在原厂菜单重新选择 NTSC、UHD30p、PRO，再回照片模式。如果再次卡死，断电恢复后先回传 SD，不继续按应用或采样。
3. 应用通过后再做短测：启动 **STAGE COUNTERS**，确认 **ON / STOP+SAVE**；视频取景 5 秒，回照片模式停止保存，等到 **COUNTERS SAVED - SAFE TO CONNECT USB**。
4. 前两步均通过后，才录原计划的全宽／裁切对照。两段使用相同机位、场景、曝光、焦距、白平衡和对焦；NTSC、UHD30p、PRO，保持既有码率，BUS QOS A/B 默认。每段分开开始和保存：**取景 5 秒 → 录像 25 秒 → 停录后等 5 秒 → 回照片模式停止保存**。
5. 全部保存后再连 USB，保留新安装日志、VIDEO_FULL_*、VIDEO_STAGE_* 和 MP4。新版 VIDEO_FULL_* 会增加 install-phases.log；请一起保留。

仍保存三个采样文件。HEVC 断点继续停用；用 PC/R10P_EP_OBSERVER/analyze_r10p.py 分析。EP 回调关联只证明处在同一 IPC 活跃窗口，尚无 Y/UV 缓冲身份闭环；缺失、重复或顺序不符不会当作有效阶段耗时。
