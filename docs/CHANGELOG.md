## 0.4.0 RC5 — 2026-11-19

- 普通非零 LUT 提交后，影片 LUT 默认开启；手动关闭和全零原厂基准保留。
- EV+WiFi 从影片 LUT 开关改为既有 V‑Log 事务的开关；组合键释放后提交，菜单监听不重复派发。
- 双击 EV 取代三按，打开当前已应用 LUT／Log LUT 及参数；单按原功能保留。
- 详细页内切换 V‑Log 后刷新输入范围；保留 OK 提交、菜单保持和半按返回。
- 新增真实 ARM 快捷派发／按键验证和11组 shell 操作验证，正式 RC4 升级回放通过。
- SD 1281 个文件读回通过；RC5 独立实机回执待补。核心库、RTOS、原生 SRW、RC4 重载工具和32张LUT不变。

## 0.4.0 RC4 — 2026-11-19

- 根据 metol 已补全的单次流程实现取景 EOF 同步、3DLUT DMA 完成确认及 Access 清理；装载失败保留 pending。
- 普通／Log LUT 编辑改为 OK 才装载，保持菜单；三按 EV 按已应用状态打开详细页（RC5已改双击）。
- Log 事务等待原厂 Gamma 排队确认，再作最终装载；保留先恢复原厂 Gamma 的优先级。
- 视频规格使用原厂命令重新提交，处理其原厂 GUI 刷新导致菜单退出的问题。
- 新加载器与 SRW 工作锁互斥；SRW 自己的清理明确跳过新硬件入口。
- 用户随后反馈“效果很好”；不扩展为所有硬件状态已认证。

## 从 R10k 到正式包路线的交接摘要

- R10l–R11f 延续全宽帧率和内部流水线研究；采样／对象／缓冲关联逐步增加，但没有形成真实30p修复或充分的硬件上限证明。
- R11g 优先原生24p，用户自行检查后认可可用。
- 随后完成 Gamma 重装载、SRW 相对曲线取证、曝光／颜色及高光量化分析；当前转到8bit V‑Log／V‑Gamut兼容路线。
- SRW 回归曾在资源、LUT及Gamma门控等处出现，已恢复；正式包保留接口和电脑分析优先原则，不再自动增加机内诊断工作流。

旧定量结论不反向改写，参见历史报告；详细接续见 [RC5交接](HANDOFF_20261119_RC5.md)。
