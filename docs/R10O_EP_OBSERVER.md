# R10o 单观测点实现与证据

依据远程 main 的交接档案（2d7a9c7a86f93504b89315524fe6a6768ea21086，docs/CURRENT_STATUS.md 与 HANDOFF_20261110.txt）以及本次 R10n 实机回传，优先拆分全宽普通帧约 42.48ms 的处理区间。用户已完成 100／80／70 码率对照，几乎不变，因此本版没有重复码率、CPU、单桥 QoS 或 DDR 档位试验。

## 已确认的原厂入口

P7.bin（SHA-256 f8e417cb5b55768851ba7e2b8017d3a98dc0b0c8444cc0a5061265cc08dbbf7f）中，0x801cab24 函数引用原厂字符串 `(_callback_wdma2_done) Done!`。原厂注册逻辑将 CORE_WDXI2_EOF、port 7、bank 0 路由到此函数；拥有者在 0x8153cb28 + 0x70，回调槽为 0x817d8adc。bank 1 的 0x801ca9a8 未修改。

仅在 0x801cab38 的一个 ARM 指令处增加跳转。该处位于原厂拥有者非空检查之后，原始 LDR r3,[r0] 在返回路径执行一次，然后继续原厂 MOV r1,#7 和通知 (7,0x15)。寄存器、CPSR、栈、原厂通知、IRQ enable/ACK 均保持原有行为。完整函数对照回放验证原厂通知只调用一次。此点是软件回调到达时刻，不能直接等同硬件锁存的 DMA 完成、缓冲释放或 HEVC 输入退还。

## 记录布局

原有五个时间边界全部保留，再增加 EP WDMA2 回调时刻。仍只租用原厂 TMC 280 字节，截止 0x817dbce0 前；原厂字符串日志不在租约内。现有两个代码区和已停用 count helper 内增加固定观察代码，无新 RTOS 分配。

256 字节逐帧区改为 schema 6：32 字节实时头，7 个 32 字节记录，每项依次为 sequence、HW、SRAM IRQ、start IRQ、final IRQ、IPC callback、flags、EP callback。逐项提交仍以 sequence 最后写入；100ms 独立读取保持不变。容量由 8 帧减为 7 帧，覆盖丢失通过计数和序号间隙明确报告。序号回绕跳过零。

flags 的 0x20 表示本 IPC 活跃窗口在 HW 提交后观察到 EP 回调，0x40 表示窗口内两次或更多；只保留首次时间。窗口外事件另计数，不能挂到上一帧。TMC 前缀含首次 EP tick、全部 EP 回调计数、窗口外回调计数、保留零、环游标、原有 count 指针。切换模式只清当前 EP tick，保留累计计数和已有记录。

frame-flow.bin 升为 fast schema 2，每条 312 字节，增加双读一致的 EP 前缀计数。读取、导出和三文件保存规则不变。分析器兼容旧 fast schema 1 与原 producer schema 4／5；新增 EP 覆盖率独立报告。原有完整帧覆盖不能代替 EP 点覆盖。当前窗口关联尚无 Y/UV 缓冲身份闭环。

## 本地验证及边界

35 项真实 ARM 指令观测检查、2400 帧时钟模型、678 个事务写入故障点、18 组生产采集器启动／保存／恢复检查、38 项菜单协议检查、7 组生产者到分析器检查，以及 5 项采样后模式切换和新入口保护检查通过。旧实机样本 2208 帧及其 counts／HEVC 分析结果一致。

这些回放使用真实 ARM 指令和原厂函数；OS、时钟外设、缓存边界仍有模拟。没有覆盖真实相机内核、MMIO、缓存一致性时延、取景与录像稳定性。R10m 的无 fork／ptrace 生产采集器、被动启动、100ms 菜单协议修复和 HEVC 断点停用保持有效；全宽配置操作原有的挂载机制仍存在，不能据此宣称硬件冻结已修复。

## 收到新实机文件后的判断

先核对相机安装日志中的 recovery-r10o-ep-wdma2-observer、菜单版本、采集器 revision、配置事务和 producer schema 6，再按原计划比较全宽／裁切。EP 点应有足够单次命中，且时序处于 HW→final IRQ 内，才统计两段耗时。

- 新增延迟主要在 HW→EP：继续细分 IPC DMA/core 与 EP 主输出，关注内部像素流量、缩放配置和访存；不能凭码率无变化排除内部 DDR。
- 新增延迟主要在 EP→final IRQ：优先核对回调语义、帧身份、通知顺序和缓冲握手，再选择一个原厂 HEVC 提交／释放边界；不恢复 R10l 的通用 IRQ／硬件断点线程。
- EP 只有窗口外命中、重复或顺序不符：先建立原厂缓冲身份关联，不计算伪造的阶段差值，不同时更改多条处理路径。

不替换整套 QHD init/update，不重新启用 HEVC 断点，不读取会配置或重启监视器的 TDC/RO 控制，不格式化、修复或清理 SD。
