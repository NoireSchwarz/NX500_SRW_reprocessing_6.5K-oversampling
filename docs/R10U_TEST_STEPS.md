# R10u 短测：IPC 控制器 0 缓冲关联

本版用于继续定位全宽 4K 的慢区间，尚未证明帧率改善。保留 event10，新增原厂 IPC 成功完成通知入口；该点在最终 IRQ 之后，用来核对请求、输入缓冲和交接延迟，不把它称作 43ms 内部的硬件中点。

本轮仅测 **NTSC、UHD30p、PRO、FULL WIDTH 4K 30P**。沿用当前码率、机位、曝光及默认 BUS/QOS，不重复 100/80/70 码率比较。

1. 将 SD 卡装回相机，等待本次安装完成。确认补丁视频页显示 **R10u IPC BUFFER LINK**。
2. 完整关机后取出电池约 10 秒，再装回开机，断开 USB。这一步必须做：R10u 更换了观测代码，不能继续使用上一版本尚在运行的 RTOS 状态。
3. 在照片模式应用 **FULL WIDTH 4K 30P**。应用成功后，按提示到原厂菜单重选 **NTSC / UHD30p / PRO**，再回照片模式。
4. 先做 5 秒短测：开始 **STAGE COUNTERS**，确认显示 ON / STOP+SAVE；等待 5 秒并检查菜单与按键仍正常；再按一次，等待 **COUNTERS SAVED - SAFE TO CONNECT USB**。照片模式没有逐帧记录不算失败。
5. 短测正常后，再启动 **STAGE COUNTERS**，退出补丁菜单，进入视频取景。
6. **取景 5 秒 → 录像 10 秒 → 停录后取景 5 秒**。
7. 回照片模式，停止并保存 **STAGE COUNTERS**，等待 **COUNTERS SAVED - SAFE TO CONNECT USB** 后再接 USB。
8. 保留所有新 `VIDEO_FULL_*`、`VIDEO_STAGE_*` 目录和对应 MP4。不要删除旧记录，也不需要再次测试原生裁切或切换码率。

若应用报错或相机失去响应，记录发生阶段和屏幕原文，停止重复应用；断电恢复后保留卡上目录。不要格式化、清理或修复 SD 文件系统。

下次检查应确认安装日志为 `recovery-r10u-ipc-buffer-link`，相机内部清单与本次包一致；采集器为 `R10u IPC_BUFFER_COUNTERS`，producer 为 **10 / magic 0x41544c56**。仅把文件写到 SD 不代表相机已安装或运行 R10u。

稳定录像段将分别检查：event10 每请求命中数、owner/来源关联；输入 CImage 与控制器 0 RDMA0 地址在提交和成功通知时是否匹配；输入/输出描述符是否改变；独立类型快照是否命中同一个请求；IRQ 到成功通知、成功通知到下一次提交的时间。

记录采用原有 280 字节固定区、4 槽、完整 26MHz 时间戳，仍每 100ms 读取。读取落后、环覆盖、失败快照和缺失事件都会明确标记；照片模式或切换期间出现缺口时，不能宣称全程覆盖完整。HEVC 断点追踪仍停用。
