R11n：新中灰 Log 曲线 + 三星官方还原 LUT，两轮 SRW 测试

安装：
1. 安全断开USB，关机再开机，让SD安装包运行。不要打开补丁菜单或采样器干扰安装。
2. 安装结束后正常关机，再开机一次。进入补丁的视频页应显示 R11n SRW MIDGRAY TEST / 24P。
   显示R11n只说明菜单已更新；最终仍以安装日志、模块清单及本轮Gamma审计为准。

测试：
1. 本次开机后拍一张 RAW+JPEG，建议M档、固定白平衡，画面包含普通中间调、暗部和亮部。
   在SRW页面选定这张SRW。原厂同名JPEG作为对照，后面两轮保持同一张SRW。
   如果继续使用已验证的灰阶SRW，则无需补拍；选择SAM_0420.SRW即可。
2. SRW页的GAMMA选择 LOG MIDGRAY +1.33；LUT选择 OFF / ORIGINAL。
   执行 AUTO + COMPARE，等待完成并返回菜单。这张是新曲线的Log直出，仍会显得灰。
3. 保持同一SRW和 LOG MIDGRAY +1.33，把SRW的LUT改成 Samsung Log Rec.709（文件ID SLOG_REC709）。
   该参考LUT会直接出现在SRW选择器，不需要先收藏。不要另行在主滤镜页应用。
   再执行 AUTO + COMPARE，等待完成。这张是相机内使用官方还原LUT后的输出。
4. 保存完成再连接USB，保留原厂同名JPEG、两张新输出及本轮INIT/JOB日志。
   JPEG输出沿用原有命名规则，不会覆盖输入照片。不要手动删除历史记录。

预期：灰阶SRW的本机18%数字格，新Log约161码，官方还原后约169码。
实际相机、JPEG量化和原厂LUT17点插值可能有小偏差，需用本轮文件验收。
若要回到既有重显影，GAMMA选SOURCE 19，LUT选OFF / ORIGINAL。

范围：只新增SRW预设，原厂、SOURCE19、LIFT、LINEAR和旧LOG均保留；录像Log曲线不变。
新预设使用标准Samsung编码公式，将本机数字线性输入乘2.520358943；不是物理灰卡18%认证。
当前SRW预设只改Gamma，没有新增BT.2020色域矩阵；彩色结果仅供观察，先验收亮度。
官方原版65点LUT保存在 NXDEMO51/R11N_REFERENCE；相机使用由它生成的现有17点表。
照片、录像、完整备份和历史日志均保留。不重复码率测试，不运行文件系统修复。
