R11p CLEAN LOG：安装与一次合并短测

1. 安全断开相机USB，正常关机待写卡灯熄灭，取出电池约30秒，再装回电池开机安装。
   安装完成后再次正常关机、取电池约30秒、开机。需清除旧开机的Gamma租约，不能把SD写入当作安装成功。
2. 确认视频页显示 R11p CLEAN LOG / 24P。先在照片待机、USB断开时选择 SAMSUNG LOG DIRECT。
   无需手动选择NXLOG_REF、100%或视频LUT。程序自动准备包内中性表，菜单显示LOG直出／滤镜锁定。
   到LUT页尝试应用一个风格或切视频LUT，应提示 LOG MODE - RESTORE GAMMA TO USE LOOKS，画面不应改变。
3. 录一段约10秒Log，停止录像，等写卡结束，回照片模式。在视频页恢复原厂Gamma。
   恢复成功后滤镜选项应重新可用。再录约5秒原厂，停止并等待保存完成后连接USB，检查安装日志及两段录像。

出现 ERROR / RESTORE 或 CLEAN_LOG_* 错误：停止录像、回照片模式，重试恢复Gamma；不要删除运行租约或会话备份。
若恢复报告清理未完成，保留日志；必要时正常关机、待写卡结束，再取电池约30秒。不要反复重装或进入核心库激活。
不需要重做码率、白平衡、ISO阶梯、灰阶或SRW曲线测试。

标签与后期：按用户最终决定，本包不修改相机原片头信息，也没有后台自动改文件进程。
Log原片仍沿用原厂709标签。剪辑时必须覆盖输入解释：BT.2020/D65原色、Samsung Log输入、8bit full range；
YUV解码矩阵仍使用原厂BT.709。不要因为原色是2020就把YUV矩阵、传递函数一起切成2020，更不能标成PQ/HLG。
颜色还原和调色放在电脑上；本机工作曲线和曝光标度沿用R11o，不能据标签声称完整标准色准。
需要时使用PC工具copy_slog8_tags.py，仅针对确认的Log直出片创建新的标签副本；不会覆盖原片。
副本将MP4 colr及HEVC SPS都设为原色9、传递未指定2、矩阵1、full range。
副本仍需在软件里明确选择Samsung Log／应用所需变换，并避免自动色彩管理重复处理。
