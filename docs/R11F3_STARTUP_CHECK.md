# R11f3 启动库只读诊断

R11f2 已安装成功，但普通关机与取电池后的新映射仍是原厂 libmmfcore.so（inode11997），而安装时提交的新库为inode45。采集器源码和SD二进制均已认可R11f修改库，暂不放宽校验，不再重复替换库。

本包只采集报告，不安装模块、不替换内部库、不修改RTOS／启动配置，不清除快照，不做文件系统修复。

1. 安全断开USB，正常关机再开机。诊断将自动执行。
2. 等约20秒，再接USB。此次不用按COUNTER、应用全宽或录像。
3. 保留新出现的 `NXDEMO51/STARTUP_CHECK_*` 文件夹。`DONE` 表示报告收集完成，不代表采样已恢复。

报告同时保存内部采集器／菜单及脚本摘要、旧采样注册信息与最多16KB状态头，不清除RAM数据。报告包括当前文件系统读到的三份库的元数据、摘要及原始文件，libmmfcore全部保留别名的摘要，相机自身文件系统可见的库与映射背后实际文件（内核支持时）、当前相机映射、PID／启动时刻、只筛选加载器相关的环境，启动模式、休眠快照标记、挂载表与内核日志。启动触发文件会在摘要匹配后移入本次报告保留，避免再次执行。

若当前库已被还原为原厂版，检查启动路径／别名恢复；若当前库为修改版而进程仍用原厂版，重点核实快照恢复／旧映射。固件内存在闪存休眠快照代码只是候选机制，须以本机报告确认。不会因为取电池仍失败而继续重复要求重启。
