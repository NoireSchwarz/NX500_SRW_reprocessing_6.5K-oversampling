# R10o：EP 主输出完成观测

本版用于定位全宽 4K 约 43ms 的处理区间，还没有证明提高帧率。保持原来码率；不再测试 100／80／70 切换。照片、录像和历史日志全部保留。

1. 安全弹出 SD，装入相机完成安装。安装后**完整关机再开机，断开 USB**。进入补丁视频页，确认显示 **R10o EP OUTPUT OBSERVER**。部署到 SD 并不等于相机已经运行 R10o。
2. 在照片模式应用 **FULL WIDTH 4K 30P**。按提示在原厂菜单重新选择 NTSC、UHD30p、PRO，再回照片模式。这个步骤才安装本版 RTOS 观测点；仅在刚开机时按采样键不会安装它。
3. 先做短测：启动 **STAGE COUNTERS**，确认 **ON / STOP+SAVE**；退出菜单进入视频取景 5 秒，确认按键正常；回照片模式停止保存，等到 **COUNTERS SAVED - SAFE TO CONNECT USB**。如报错，保留屏幕原文和卡上新目录，不反复按开始。
4. 短测通过后，录两段固定设置的对照：先 **FULL WIDTH 4K 30P**，再 **CROP 4K 30P / 80M**。两段均为 NTSC、UHD30p、PRO，保持相同机位、场景、焦距、曝光、白平衡和对焦，BUS QOS A/B 保持默认；码率使用既有配置。
5. 每段依次执行：照片模式应用设置、按提示重选原厂 UHD30p／PRO；启动 STAGE COUNTERS；**视频取景 5 秒 → 录像 25 秒 → 停录后等 5 秒**；回照片模式停止采样并等待保存完成。两段分开开始和保存，便于区分窗口。
6. 全部保存完成后再连接 USB。保留最新安装日志、新增 VIDEO_FULL_*、VIDEO_STAGE_* 和对应 MP4。

仍保存 counts.bin、frame-flow.bin、hevc-flow.bin 三个文件。HEVC 断点仍停用；该文件显示停用属于正常情况。使用 SD 上 PC/R10O_EP_OBSERVER/analyze_r10o.py 分析新格式；旧版本分析器可能不认识新增时间点。

这次需要比较的是硬件提交至 EP 原厂 WDMA2 回调、该回调至最终 IRQ 的两个区间。缺失、多次触发、出现在区间外的回调会明确标记并排除耗时统计；不能把它们当作零耗时或完整覆盖。
