R11h 原厂 Gamma 重装载合并短测
2026-11-17

本包验证原厂 ISP Gamma 的 19 点/432 字节链，不是后段 3D LUT 换表。无需测试上一轮 NXLOG_REF_V1 / NXLOG_TEST_V1 文件。
原全宽 UHD24p、HEVC 核心库和既有全宽 RTOS 代码保持不变。检测包尚待实机确认，不宣称标准 Samsung Log 或新增动态范围。

安装与准备
1. 安全弹出 SD，装入相机完成安装。安装完成后正常关机再开机一次，断开 USB；打开视频页确认显示 R11h NATIVE GAMMA / 24P。之后四段之间不要关机、拔电池或重装。
2. 如果以前应用了后段 LUT，先在 LUT 页关闭“视频 LUT”，选“还原 LUT”并退出半按快门；本轮保持后段 LUT 关闭。这只是排除已有滤镜干扰，不再测试 LUT 换表。
3. 固定机位、曝光、白平衡、对焦和拍摄设置；画面放暗部、白纸和有颜色的物体。沿用已正常工作的 4K24p 设置即可，不改码率，不开 STAGE COUNTERS / BUS 实验。不要在本轮拍照片或做 SRW 显影。

四段合并测试，每段约8秒
A1 原厂：保持 ISP GAMMA RELOAD 行为 FACTORY，录8秒，停止录像并等写卡灯熄灭。
B 提亮：回照片模式，选视频页最下方 ISP GAMMA RELOAD，按OK一次切到LIFT。若显示 LIFT GAMMA QUEUED，退出进入视频取景，再录同场景8秒，停止并等写卡结束。
C Log：回照片模式，再选同一行按OK切到LOG。显示 LOG GAMMA QUEUED 后录同场景8秒，停止并等写卡结束。这里使用已有研究的前段19点Log候选，输入归一化尚未校准，先验收是否实际改变Gamma链及画面。
A2 恢复：回照片模式，再按一次同一行请求恢复。显示 FACTORY GAMMA QUEUED 后录同场景8秒。该恢复通过原厂计算和提交后才撤下实验回调，不能把点过按钮当作恢复已经完成。

若显示 GAMMA WAIT
退出补丁菜单，进入视频取景约3秒，回照片模式重新打开菜单查询。只有查询到原厂队列提交后才继续；仍为WAIT或出现失败时，可在同一行按OK请求原厂恢复，再停止本轮并保留记录，不反复切换或重装。等待状态没有被计作成功，等待期间OK的作用是恢复，不是推进下一条曲线。
“QUEUED”只证明原厂已提交该Gamma参数，尚不等于硬件完成或录像像素已生效。最终以四段MP4和日志共同验收。

收尾
完成A2后回照片模式，重新打开视频页读取一次状态，确认FACTORY；退出菜单，等写卡灯熄灭再连接USB。保留四段MP4以及新增 GAMMA_R11H_* 目录，照片、旧视频、完整备份和历史日志全部保留。

状态与内存
实验回调使用一次实际分配的2MiB CAP租约，同一开机内反复切换复用它。后续命令的临时CAP会归还；回调代码所在CAP即使恢复后也不立即释放，防止旧返回地址仍引用它。真正重新启动系统后回收，普通休眠式关机不应被当作已经回收。测试最后要明确恢复原厂；仍有此租约时，安装器会拒绝再次覆盖模块，避免覆盖仍在使用的回调版本。
不修改核心库，不重启相机应用进程，不进入恢复分区，不重复码率测试。
