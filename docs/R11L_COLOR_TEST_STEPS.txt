R11l 最小颜色残差补测：三段录像，一次开机

这次需要补拍。目的只补齐录像期间真正存在的 Gamma、CC、R2Y、SE及对象状态，不试新曲线、不做相机内拟合。继续用之前的同一张灰阶／彩色图。

安装与准备
1. 按以往方法安全退出电脑上的 SD／相机 USB。正常关机、待写卡灯熄灭，取出电池约30秒再装回，以清除可能留存的旧 Gamma 租约。
2. 使用卡上的新安装触发文件安装。新安装修订号为 recovery-r11l-color-readonly。安装完成后完整关机再开机。视频页应显示 R11l COLOR READ ONLY / 24P。SRW 页保留 R11k3c，Log 曲线仍为已验证的 R11j，这是正常的组件版本组合。
3. Tab S7+ 沿用自然模式、原来的固定高亮度。显示本包 R11L_COLOR_CHART/01_static_calibration_sRGB.png（与前轮相同文件）。暗室、固定机位，四角标记入画；先稍微虚焦消除网纹，然后三段都保持同一对焦。
4. M档，ISO200、F4.0、1/60。沿用已稳定的录像分辨率与帧率。锁定白平衡，三段保持同一固定色温／自定义档；如原设置记不清，统一固定6500K并注明。屏幕亮度、构图、曝光和镜头均保持不动。
5. 继续使用 NXLOG_REF_V1、100% 和视频 LUT ON；视频 Gamma 应为 FACTORY。所有准备在启动检测器前完成。无需执行 SRW 测试。

合并录像（开始检测后尽量在5分钟内完成）
6. 视频页选择 COLOR OBSERVE，看到 ON / STOP+SAVE。普通 STAGE COUNTERS 不参与本轮。
7. A1：保持 FACTORY，进入视频取景，录8～10秒静态图后停止。
8. 待写卡完成、回照片模式，在 SAMSUNG LOG 8BIT 一栏切到 SLOG8；再进入视频取景，录8～10秒，停止。此段为B。
9. 待写卡完成、回照片模式，在同一栏恢复 FACTORY；再进入视频取景，录8～10秒，停止。此段为A2。两次曲线切换都在停止录像后进行，不碰光圈、ISO、快门或对焦。
10. 待录像保存结束、回照片模式，再点 COLOR OBSERVE 停止并保存。明确看到 COLOR SAVED - SAFE TO CONNECT USB，再连接电脑。保留三段MP4与新 COLOR_R11L_* 目录、GAMMA_*记录和安装日志。

状态处理
- STOP VIDEO / WAIT FOR COLOR SAVE：先停止录像并等写卡结束，再查看状态。
- COLOR IN RAM：保持相机开机，断开USB，在停止录像后再点一次 COLOR OBSERVE 保存。
- SAVED / NO VALID BANK0 / USB SAFE：文件已保存，但未取得有效bank0参数。仍请保留文件交电脑分析，不自行连续重测或换设置。
- FULL表示5分钟的记录预算已用完；停止录像后保存即可。不要为了本轮重复码率或曝光阶梯测试。
- 开始失败或曲线切换失败：停止后续步骤，保留原文与现有记录；不要反复重试。

电脑端验收
先确认相机安装与运行版本，再按MP4文件名关联录像期间快照；原厂A1、LogB、原厂A2各应取得至少约10个稳定样本。检查注册链／bank／上下文、描述符、两路Gamma、两组CC、R2Y及SE源／缓存。变化中的样本保留原值并标为不一致。最后比较A1/A2稳定性，连同既有SRW及两档曝光录像做颜色留出检验。

本图没有仪器测量值，用于相对链路识别；它不是实物灰卡或绝对色度标定。检测包不改变相机处理曲线或矩阵。照片、录像、原始固件、完整备份和历史日志全部保留。
