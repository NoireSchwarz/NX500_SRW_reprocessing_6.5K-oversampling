R11h1 Gamma 快照读址修复短测
2026-11-17

本包修复 R11h 的 GAMMA_BEFORE_SNAPSHOT_FAILED，保留已完成 LIFT 原厂提交的 RTOS 回调。无需重复码率或旧3D LUT换表测试。

更新前必须彻底断电一次
1. 安全弹出 H 盘并断开相机 USB，正常关机，等机身写卡灯熄灭。
2. 取出电池约30秒，确保 USB 也已断开，再装回电池开机，完成 SD 新包安装。旧 R11h 的回调占用内存在真正断电后才清除；普通电源键休眠不能替代这一步。
3. 安装结束按原流程关机再开机，打开视频页确认 R11h1 NATIVE GAMMA / 24P。若安装日志提示 GAMMA_LEASE_REQUIRES_RESTORE_AND_ACTUAL_BOOT_BEFORE_MODULE_UPDATE，说明还存在旧开机租约，停止重复安装，按第1、2步实际断电；不强行跳过检查。

同一次开机的四段合并测试
沿用本轮正常录像的4K24p设置，后段视频 LUT 关闭，固定曝光、白平衡、焦距和对焦。本次已保存的两段实际为4096×2160/24p，不把它们当作3840全宽映射的证明；本轮只验收Gamma，不切换码率或重查全宽性能。准备包含白纸、中灰和暗部的同一画面。
A1 FACTORY：确认末行 ISP GAMMA RELOAD 显示 FACTORY，录约8秒。
B LIFT：停止录像，等写卡灯灭，回照片模式，选 ISP GAMMA RELOAD 按 OK 切至 LIFT；显示 LIFT GAMMA QUEUED 后进入视频取景，录同场景约8秒。
C LOG：停止、等写卡灯灭、回照片模式，再按同一行切至 LOG；显示 LOG GAMMA QUEUED 后录同场景约8秒。
A2 FACTORY：停止、等写卡灯灭、回照片模式，再按同一行请求恢复原厂；显示 FACTORY GAMMA QUEUED 后录同场景约8秒。
四段之间不要重启、拔电池、重新安装或开 STAGE COUNTERS；不要在本轮拍照片或做 SRW 显影。

WAIT、错误与恢复
WAIT 时先退出菜单进入视频取景约3秒，回照片模式重开菜单查询。持续等待或报错时，同一行 OK 将请求原厂恢复，不会继续推进下一条曲线。
恢复仍执行原有固件、租约、空闲和提交校验；只有诊断快照失败不再单独阻塞恢复。恢复前快照若不完整，会在 result.json 明确标记 restore_before_snapshot_bypassed，不能算作快照成功。
如恢复也无法确认，停止测试，保存日志，正常关机后实际断电清除回调，不反复切换或修改核心库。
QUEUED 只代表原厂参数已提交，不代表像素或DMA已确认生效。LOG仍是待标定的19点候选。
