# NX500 YuNet 32 人眼對焦

在本目錄執行 `python build.py --zig <Zig 0.13.0 的路徑> --yunet --test`。
輸出為 `out/nxl-eye-af-yunet.so` 和 ARM 回放執行檔。使用 Python 3.10+、
NumPy、ONNX 1.17、Unicorn 2.x 和 pyelftools。產生器核對 OpenCV Zoo 的
YuNet 2026may 權重 SHA-256，再使用 `model/yunet-calibration.json` 的量化範圍。
重新校準使用 `model/pack_yunet.py --calibrate`，需要 32×32 BGR 樣本和 ONNX Runtime。
[模型版本、論文與 MIT 授權](model/YUNET.md)

卷積和中間張量使用 INT8，每個輸出通道獨立量化，NEON 執行乘加與縮放。
輸出使用查表和少量浮點幾何。工作區包括 10 KiB 張量及 3 KiB BGR 裁剪。
相機端使用原廠選定的主臉和 528×352 半平面取景緩衝區。多人入鏡時只對
主臉找眼，保留其他臉框與原廠測光統計。原廠切換主臉索引時，先清除舊眼點。
電腦對照採用全範圍 BT.601 與 CbCr 交錯。機身取景色度語義和暗光效果
須以實機驗證。

正置畫面左眼優先，左眼座標未通過幾何檢查時可提交右眼。眼框以臉寬和臉高的
約五分之一為基礎。528×352 對焦座標中的邊長至少為 18，臉框每邊超過 32 後，
每增加 8 像素便把該邊的下限加 1。正置時將眼框中心稍往外、往上調整。
同一眼睛的小幅位置和尺寸變動使用 2 像素防抖，眼框始終限制在臉框內。
模型失去可信眼點時，沿用追蹤期限，再交回臉框。穩定追蹤時約每 420 ms 更新眼點，
兩次更新之間隨原廠臉框移動及縮放。連續三次超過 20 ms 後改為每秒更新，
連續三次不超過 12 ms 後恢復。機內狀態會記錄 `policy=primary-v2`、
`focus=stable2`、最長耗時、快慢切換次數和消除抖動的幀數。

原廠 ARM 回放中，臉框邊長 54、90、144 時，對焦區邊長分別為 20、25、32，
在 720×480 主屏合成座標中繪成 26、34、42。維護者在一台 NX500 實測後回報
明顯改善。後續可用受控的追焦與光學測試量化效果。

Focus2 更新從已實測的 YuNet Primary v2 快啟接續。`../rebuild/yunet/` 的打包及驗證
使用已保存的前代包、原廠 1.12 韌體及匹配的開發工作區。模組可單獨構建與回放。
